# Tablet Annotator

Native Android tablet annotation canvas with a touch-friendly floating toolbar: pen, highlighter, eraser, colour choices, undo, and clear confirmation.

## Get the APK — no installation needed

Every update starts a GitHub Actions build. Open the **Actions** tab on GitHub, choose **Build Android APK**, wait for the green check mark, then open that build and download the **annotatebar-debug-apk** artifact. Copy the downloaded APK to your Android tablet and open it to install.
